## 職務経歴詳細

### ファインディ株式会社（2024/05〜現在）

データソリューションチーム所属。データエンジニアとして、全社横断のデータ基盤の構築・運用、管理会計データモデリング、BI ダッシュボードや AI エージェント開発を担当。モデリング規約やデータガバナンス体制の策定、事業部への運用委任までを主導。

#### データ基盤の構築・運用

- Findy Freelance のデータ基盤の設計・開発・運用
  - BigQuery + dbt を用いたプロダクトデータ基盤を構築。社内プロダクト DB 5 種・外部 SaaS 12 種を含む約 20 のデータソースを統合し、約 1.3 TB・7,000 テーブル超の分析環境を運用
  - staging / dimension・fact / mart のレイヤー構成と層ごとの責務をモデリング規約として定義
  - ビジネスプロセスごとにファクトの粒度を定義し、企業・ユーザーなどの適合ディメンションと組み合わせたスタースキーマを設計
  - 広告媒体・行動ログを含む複数データソースを統合し、TROCCO で CRM・マーケティングツールへ連携するデータマートを構築
  - dbt の実行環境を dbt Platform へ移行し、データアナリストによるモデル開発からデプロイまでのセルフサービス運用を実現

- データガバナンスの設計・運用
  - 複数の Google Cloud プロジェクトに分散していた基盤を単一プロジェクトへ統合し、東京リージョンに移行
  - 個人情報を含むデータにポリシータグによる列レベルのアクセス制御を適用し、スプレッドシートへの持ち出しによって権限管理の対象外となるリスクを解消
  - Cloud DLP によるマスキング処理を導入し、個人情報を含むデータを分析用途に提供できる環境を整備
  - BigQuery データセット・サービスアカウント・IAM と GitHub リポジトリの権限を Terraform でコード管理
  - 半期ごとの権限レビューと未使用データの棚卸しを、チームの運用サイクルとして定着
  - DMBOK に基づくデータマネジメント成熟度アセスメントを半期ごとに主導し、データガバナンス領域のスコアを 0.5 → 3.2（5 段階）へ改善

#### 管理会計データモデリング

- 経営企画向け管理会計基盤の設計・構築（2025）
  - スプレッドシートやネストされた BigQuery ビューに散在していた会計実績の算出ロジックを、4 事業部以上で共通利用する BigQuery・dbt のデータモデルへ集約。属人化していた月次実績の算出プロセスを自動化し、所要時間を 3 人日から 10 分へ短縮
  - 総勘定元帳を起点として、売上・費用・原価をトランザクションファクトとしてモデル化。見通しデータは定期スナップショットファクトとし、実績データと同一の粒度・構造で設計
  - 配賦率など変更頻度の高い業務ルールを、業務部門が自律的に管理・変更できる仕組みを構築
  - Looker で P/L 指標・人件費・人員をメジャー化し、連結・事業部別・共通部門の内訳でドリルダウンできるダッシュボードを構築
  - Looker の会話分析エージェントを整備し、自然言語での予実分析にも対応

#### AI エージェント開発

- 事業部横断の CRM 検索エージェント
  - 複数プロダクトの展開で顧客情報がサイロ化していた課題に対し、ADK と MCP を用いた Slack ベースの企業検索エージェントを開発
  - SQL スキルのない営業・CS メンバーでも共通企業マスタを検索できるよう、エージェントへ提供するデータの範囲と権限を設計
  - 運用開始 1 ヶ月でインサイドセールス・カスタマーサクセスメンバーの約 40％ が利用

- 社内 AI プラットフォームの構築・運用

## 自己PR

### ビジネス課題をデータソリューションへ落とし込む力

経営企画や営業・CS などの事業部門から課題を直接ヒアリングし、業務要件を指標・データモデル・システムへ落とし込んできました。管理会計基盤の構築では、複数部門に分散していた算出ロジックを再設計し、月次実績の算出時間を 3 人日から 10 分へ短縮しました。技術の導入自体を目的とせず、利用者や業務プロセスを理解したうえで、継続的に活用される運用まで一貫して設計できることが強みです。

### データ基盤のゼロからの構築・運用

データ基盤のない状態から、要件定義・技術選定・設計・構築・運用までを一貫して担ってきました。構築して終わりではなく、データアナリストや事業部メンバーが自律的にデータを活用できる状態をゴールとしています。直近では、事業部メンバーが自らデータや業務ルールを管理・変更できる仕組みを整備し、データチームを介さずに活用サイクルが回る状態を実現しました。

### データガバナンスによる統制と信頼性の担保

データの安全性と利便性を両立するため、個人情報やアクセス権限を適切に管理する仕組みを整備してきました。ルールやシステムを導入して終わりにせず、定期的な見直しを運用サイクルに組み込み、継続的に改善できる状態を構築しています。統制によって利用を制限するのではなく、利用者が必要なデータを安心して活用できる環境をつくることを重視しています。

業務部門とデータ基盤をつなぎ、意思決定に必要なデータを継続的に届けられるデータエンジニアを目指しています。事業への理解を深めながら、業務課題を指標定義やディメンショナルモデルへ落とし込み、一貫した定義で誰もがデータを活用できる環境を構築していきたいと考えています。今後は、セマンティックレイヤーや AI エージェントも活用し、利用者が必要な情報へ自然かつ安全にアクセスできる分析体験の実現に取り組みます。
